# Training Checklist

## Admin training
- [ ] Sign in and confirm branch context
- [ ] Manage users, roles, permissions and branch assignments
- [ ] Configure branches, services and providers
- [ ] Review appointments/patients without creating duplicates
- [ ] Use billing/payments/refunds according to permissions
- [ ] Use inventory receiving/transfers/adjustments/counts
- [ ] Use expenses and approvals
- [ ] Review reports using documented financial terminology
- [ ] Manage Forms & Consent versions
- [ ] Review recall/follow-up and operational tasks
- [ ] Configure management automation only after clinic decisions
- [ ] Review audit/system settings

## Front desk training
- [ ] Patient search/new patient
- [ ] Booking and real availability
- [ ] Check-in/queue/no-show
- [ ] Reschedule/cancel
- [ ] Intake/forms status
- [ ] Billing handoff and permitted payment actions
- [ ] Recall contact outcomes
- [ ] Tasks/work queue

## Dentist training
- [ ] Today/schedule
- [ ] Medical history/allergy semantics
- [ ] Draft clinical record
- [ ] Finalize and amend
- [ ] Performed treatments
- [ ] Treatment plans and price snapshots
- [ ] Prescriptions/documents
- [ ] Follow-up recommendations

## Patient portal demonstration
- [ ] Sign in/dashboard
- [ ] Appointments
- [ ] Forms & Consent
- [ ] Treatment plans
- [ ] Billing/payments/receipts
- [ ] Documents
- [ ] Recall/follow-up
- [ ] Profile/preferences
- [ ] PWA/offline limitations

Record trainer, attendees, date, questions and unresolved issues before sign-off.
