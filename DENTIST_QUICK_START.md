# Dentist Quick Start

## Today's Queue

1. Open Dashboard.
2. Review Dentist Queue.
3. Confirm patient, time, service, and branch.
4. Start Visit when the patient is ready.

## Start Visit

Starting a visit changes the appointment to In Treatment and creates or reuses the clinical visit record. The workspace keeps patient, appointment, branch, dentist, and service context.

## Review Patient History

Check:

- Allergies and medical conditions.
- Current medications.
- Prior visits and treatments.
- Documents/images where available.
- Outstanding clinical notes or follow-up needs.

## Record Treatment

1. Use the clinical workspace.
2. Select the service/procedure.
3. Confirm tooth number if relevant.
4. Record treatment description and notes.
5. Save each procedure separately if multiple treatments were performed.

The patient, appointment, branch, and dentist should already be filled from the active visit.

## Complete Visit

1. Save clinical notes.
2. Add prescriptions/documents if needed.
3. Finalize the clinical record only when ready.
4. Complete the appointment.
5. Tell staff/cashier if billing or follow-up scheduling is needed.
